# Jupiter conformance

Target: canonical WinUI 3/C# + Rust core architecture and Jupiter style standard 1.1.

No exceptions selected. This milestone contains Rust core code and project documentation only. No GUI has been built or delivered. The future GUI must import shared Jupiter.UI resources and its error-mode build check, use shared theme/accent controls, avoid NumberBox, and ship through an installer with Start Menu verification. A rendering component that requires an exception must be evaluated and recorded here before adoption.
